## 备份脚本改为 WebDAV 远端(用户追加需求)
- 备份目标从本地 backups/ 改为 WebDAV,路径与图片存储一致(共用 webdav_folder,默认 images)。
- 只保留最新一份 db:文件名 blog-backup-<时间戳>.db,上传新备份后 PROPFIND 列出 folder 内匹配文件并删除旧的。
- 脚本独立实现 WebDAV 交互(不 import server 模块,避免 db.js 初始化副作用),配置读 settings 表(webdav_*),回退环境变量 WEBDAV_*。

- 踩坑:list/restore 读不到 settings,原因是 loadConfig 没自动开库;改为 loadConfig() 内部按需打开 readOnly 连接读 settings。
- 用极简 mock WebDAV(http server 实现 MKCOL/PUT/PROPFIND/DELETE/GET)做了真实验证:连续备份只留最新、list 正确、删库后用环境变量 restore 成功。

## 备份脚本改用 Python 3.11(用户追加需求)
- 删除 tools/backup.mjs,改为 tools/backup.py:仅用标准库(sqlite3 / urllib.request / xml.etree),要求 Python 3.11+。
- 功能与 mjs 版一致:checkpoint(PRAGMA wal_checkpoint(TRUNCATE))→ 读 settings 表 webdav_* 配置(回退环境变量)→ MKCOL 建目录 → PUT blog-backup-<时间戳>.db → PROPFIND(depth1)列出 → 删除旧备份只留最新;list / restore 命令同。
- 关键实现点:urllib 用 Request(method='MKCOL'/'PROPFIND') 发自定义方法;405/409/301 忽略建目录、DELETE 404 忽略;PROPFIND XML 用 ElementTree 遍历 tag.endswith('href') 提取文件名再 unquote;sqlite 只读用 file:...?mode=ro uri 打开。
- 用 Python 版 mock WebDAV(http.server)验证:连续 3 次备份只留最新、list 正确、删库后靠环境变量 restore 成功(users=2、webdav_url 完整)。
- 定时命令改为: python3 tools/backup.py
